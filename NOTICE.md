# Content and authorship

Before the PhD / 上岸之前 was created for songsiyi2006-chem with OpenAI Codex assistance.

The runtime is self-contained JavaScript, CSS, HTML, and procedural SVG. No third-party runtime libraries, external fonts, stock images, university logos, or remote services are bundled. Screenshots depict the game itself. The vector art includes shared silhouette families and authored variants.

Questions and explanations are educational concept exercises written for the game. They have received internal checks, not independent expert review. University names are used for fictional gameplay targets; scores, requirements, outcomes, items, and dialogue do not describe actual admission standards or endorsements. Names and trademarks remain with their respective owners.

The MIT license applies to the original code, documentation, and vector artwork in this repository, including the original V1 engine/data retained for migration tests. It does not grant rights to third-party names or trademarks.

No player save files, access tokens, local authentication files, or private workspace history are distributed. Tests that optionally use a developer-local save fall back to synthetic data when that file is absent.
